# Project review (2026-11-04)

A full review of this portfolio site, made on 2026-11-04 before go-live. It covers content accuracy, design, accessibility, responsive layout, code quality, performance, security and privacy.

The review was **read-only**: no source files were changed while it ran. Every finding has an ID (for example H-01), a severity and a recommended fix.

## Files

- `PROJECT_REVIEW_SUMMARY.md`: verdict, top risks and strengths, recommended actions, and the commands that were run.
- `PROJECT_REVIEW_REPORT.md`: the full report with evidence for each finding.
- `PROJECT_REVIEW_FINDINGS.csv`: every finding in one table.
- `*.txt`: raw output of `astro check`, `astro build`, `npm audit` and the link checks.
- `screenshots/`: each page at 1440 px and 390 px, as reviewed.

## What changed after the review

The **"Fixes applied after the review"** section at the end of `PROJECT_REVIEW_SUMMARY.md` records what was changed after the review, with the commit for each fix. Later work is in [`CHANGELOG.md`](../CHANGELOG.md).

Before publishing, local file paths in the raw output were made relative, and one quote from the owner's private notes was made generic.
