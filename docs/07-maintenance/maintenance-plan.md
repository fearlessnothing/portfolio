# Maintenance Plan

| Activity | Frequency |
|---|---|
| Add or update a case study / Lab project | When a project finishes |
| Dependency updates (`npm outdated`, `npm update`) | Monthly |
| Lighthouse + broken link check | Monthly |
| Review content for accuracy and confidentiality | Quarterly |
| Update résumé PDF | When role or skills change |

## Versioning
Semantic versioning: `MAJOR.MINOR.PATCH`
- PATCH — typo or small fix
- MINOR — new case study, page or feature
- MAJOR — redesign

All changes are recorded in `CHANGELOG.md`.

## Issue tracking
GitHub Issues with labels: `bug`, `content`, `design`, `enhancement`.
