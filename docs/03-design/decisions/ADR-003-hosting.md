# ADR-003: Cloudflare Pages for hosting

**Date:** 2026-10-14 · **Status:** Proposed (confirm at deploy, Sprint 3)

## Options
GitHub Pages, Vercel, Netlify, **Cloudflare Pages**.

## Decision
Cloudflare Pages: free, global CDN, automatic deploy on every push to GitHub, preview deployments.

## Consequences
Repository must be on GitHub. Web3Forms key stored as a Cloudflare environment variable.
