# User Stories

## Recruiter
- As a recruiter, I want to see the candidate's name, role and key numbers in the first screen, so I can decide in seconds whether to read on.
- As a recruiter, I want to download a résumé PDF, so I can share it with the hiring manager.

## Hiring manager (IT / Operations)
- As a hiring manager, I want to read how the candidate made decisions and handled risks, so I can judge management ability, not just technical skill.
- As a hiring manager, I want to see measurable results for each project, so I can understand the impact.
- As a hiring manager, I want to see which work was delivered on the job and which was self-learning, so I can trust the claims.

## Technical reviewer
- As a technical reviewer, I want to open the GitHub repo and SDLC docs, so I can see how the candidate structures a project.

## Owner (me)
- As the owner, I want to add a new case study by writing one Markdown file, so the site stays easy to update.
- As the owner, I want to work from either of my two laptops, so I can continue anywhere.
